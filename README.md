# Конвертер валют

Веб-приложение для конвертации валют с использованием актуальных курсов из внешнего API. 
Реализована система аутентификации, личный кабинет, история конвертаций, избранное и новостная лента.

---

## Технологии

- Python 3.13
- Django 6.0
- SQLite
- HTML + CSS
- ExchangeRate-API
- Кеширование (встроенное в Django)

---

## Функционал

- Конвертация валют в реальном времени
- История конвертаций с фильтрацией и пагинацией
- Избранные пары валют
- Новостная лента (CRUD)
- Регистрация, вход, выход
- Личный кабинет пользователя
- Админ-панель
- Кеширование курсов валют
- Кастомные страницы 404 и 500

---

## Установка и запуск

### 1. Клонирование

git clone https://github.com/d1zy11/diplom.git
cd diplom

### 2. Виртуальное окружение

python -m venv venv
venv\Scripts\activate  # Windows
# source venv/bin/activate  # Mac/Linux



### 3. Установка зависимостей

pip install -r requirements.txt

### 4. Миграции

python manage.py migrate


### 5. Создание суперпользователя

python manage.py createsuperuser



### 6. Запуск сервера

python manage.py runserver

После запуска открой: http://127.0.0.1:8000/
